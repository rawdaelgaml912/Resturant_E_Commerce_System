# 🍽️ Restaurant E-Commerce System

A Restaurant E-Commerce web application built using ASP.NET Core MVC.

This project was developed as a training project to practice and apply backend development concepts using .NET, including database management, authentication, authorization, order management, and online payment integration.

## 🚀 Features

- User Registration & Login
- Authentication & Authorization
- Role-Based Authorization
- Product Management
- Category Management
- Shopping Cart
- Order Management
- Admin Dashboard
- Online Payment Integration with Paymob
- CRUD Operations

## 🛠️ Technologies

- C#
- ASP.NET Core MVC
- Entity Framework Core
- SQL Server
- ASP.NET Core Identity
- LINQ
- Paymob Payment Gateway

## 🗄️ Database

SQL Server is used for data storage and Entity Framework Core is used for database operations and data access.

## 🔐 Authentication & Authorization

ASP.NET Core Identity is used for user registration, login, authentication, and role-based authorization.

## 💳 Payment Integration

Paymob Payment Gateway is integrated into the application to handle online payments.

## 🎯 Project Purpose

The purpose of this project is to gain hands-on experience with ASP.NET Core MVC and apply backend development concepts in a complete training project.
